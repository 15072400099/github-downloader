设置

每个仓库会存在这个目录下的「作者/仓库名」里。

GitHub 的下载地址在国内常被阻断，默认套一层加速镜像。留空表示直连（多半连不上）。

不填 token 时接口只有 60 次/小时，浏览几个仓库就用完；填了是 5000 次/小时。 去 GitHub → Settings → Developer settings → Personal access tokens 创建一个，不需要勾任何权限。

给接口请求用。下载走镜像，一般不需要代理。
